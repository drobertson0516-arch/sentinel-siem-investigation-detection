# Incident Report

This folder contains the formal incident report for the Microsoft Sentinel-style SIEM investigation and detection project.

## Report

**SIEM Incident Report — Suspicious Authentication, Account Compromise, and External Email Disclosure**

The report documents the complete investigation of a simulated Microsoft 365 account compromise, including:

- SIEM alert triage
- Authentication baseline analysis
- Suspicious source IP and device investigation
- Microsoft 365 and SharePoint activity analysis
- Sensitive data impact assessment
- External mailbox forwarding analysis
- Incident severity escalation
- Containment and response actions
- MITRE ATT&CK mapping
- Detection engineering and KQL logic
- Recommendations and final analyst conclusions

## Training Disclaimer

This project uses synthetic telemetry in a Microsoft Sentinel-style environment for cybersecurity training and portfolio purposes. No production systems, real customer data, or live Microsoft Sentinel tenant were used.
